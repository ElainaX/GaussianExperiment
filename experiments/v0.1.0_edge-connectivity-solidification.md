# Triangle Connectivity Solidification — 代码修改方案

## 总体原则

- **不改动 CUDA 代码**（forward.cu / backward.cu / rasterizer_impl.cu）
- **所有新超参数默认值为 0**，即默认行为与原始 mesh-splatting 完全一致
- 新功能全部通过纯 Python / PyTorch 实现，梯度通过 `vertices` 正常传播
- 新代码隔离在新文件 `utils/connectivity_utils.py` 中，尽量不污染已有文件

## 一、新增文件：`utils/connectivity_utils.py`

### 功能说明

| 函数 | 作用 |
|------|------|
| `build_edge_candidates` | 每次 prune 后调用，以 KDTree 在 3D 空间中为每条边找 k 个最近邻边，排除同三角形的边，返回 `[3P, k]` 索引表（CPU tensor） |
| `connectivity_loss` | 边级软连通 loss：让每条边向最近邻边靠拢，通过 softmax 加权，按三角形重要性 × opacity 加权，完全可微 |
| `opacity_solidification_loss` | 实体化 loss：对高置信三角形的 opacity 施加 `(1 - o_i)²` 惩罚，推动其趋向不透明 |

### 完整代码

```python
# utils/connectivity_utils.py

import torch
import numpy as np
from scipy.spatial import KDTree


def build_edge_candidates(
    vertices: torch.Tensor,
    triangle_indices: torch.Tensor,
    k: int = 5,
) -> torch.Tensor:
    """
    为每条三角形边（共 3P 条）找 k 个最近邻边（按边中点 3D 距离）。
    同一三角形内的边会被排除。

    Args:
        vertices:         [V, 3] GPU tensor（detach 后转 CPU 处理）
        triangle_indices: [P, 3] int tensor
        k:                每条边的候选邻居数

    Returns:
        candidates: [3P, k] LongTensor（CPU），
                    edge j 的候选集为 candidates[j]，存储全局边编号 0..3P-1
    """
    V = vertices.detach().cpu().numpy()
    T = triangle_indices.long().cpu().numpy()
    P = T.shape[0]

    # 边端点：边 0 = (v0,v1)，边 1 = (v1,v2)，边 2 = (v2,v0)
    v0, v1, v2 = V[T[:, 0]], V[T[:, 1]], V[T[:, 2]]
    edge_a = np.concatenate([v0, v1, v2], axis=0)   # [3P, 3]
    edge_b = np.concatenate([v1, v2, v0], axis=0)   # [3P, 3]
    midpoints = (edge_a + edge_b) / 2               # [3P, 3]

    # 每条边所属三角形编号
    tri_owner = np.tile(np.arange(P), 3)  # [3P]

    # 过量查询以便过滤同三角形边
    query_k = min(k * 4 + 3, 3 * P)
    tree = KDTree(midpoints)
    _, nn_idx = tree.query(midpoints, k=query_k)

    candidates = np.full((3 * P, k), -1, dtype=np.int64)
    for i in range(3 * P):
        valid = [
            j for j in nn_idx[i]
            if j != i and tri_owner[j] != tri_owner[i]
        ]
        n = min(k, len(valid))
        candidates[i, :n] = valid[:n]
        # 邻居不足时用最后一个补齐（距离将较大，softmax 权重趋近 0）
        if 0 < len(valid) < k:
            candidates[i, len(valid):] = valid[-1]
        elif len(valid) == 0:
            candidates[i, :] = i   # fallback: 自身，D=0，梯度为 0

    return torch.tensor(candidates, dtype=torch.long)   # CPU tensor


def connectivity_loss(
    vertices: torch.Tensor,
    triangle_indices: torch.Tensor,
    edge_candidates: torch.Tensor,
    importance_score: torch.Tensor,
    vertex_weight: torch.Tensor,
    tau: float = 0.1,
) -> torch.Tensor:
    """
    边级软连通 loss：

        L_conn = mean_e [ omega_e * sum_f P_ef * D_edge(e, f) ]

    D_edge(e=(a,b), f=(c,d)) = min( ||a-c||²+||b-d||², ||a-d||²+||b-c||² )
    P_ef = softmax(-D / tau)    （matching 权重，stop-grad）
    omega_e = importance[tri] * min_opacity[tri]   （置信权重，stop-grad）

    梯度仅通过 D_edge 中的顶点坐标传播。

    Args:
        vertices:         [V, 3]，requires_grad=True
        triangle_indices: [P, 3]
        edge_candidates:  [3P, k]，CPU tensor（函数内部移至 GPU）
        importance_score: [P] or [P,1]，来自 triangles.importance_score
        vertex_weight:    [V] or [V,1]，来自 triangles.vertex_weight（logit 空间）
        tau:              softmax 温度，越小匹配越硬
    """
    T = triangle_indices.long()
    P = T.shape[0]
    dev = vertices.device

    # 提取边端点 [3P, 3]
    v0 = vertices[T[:, 0]]
    v1 = vertices[T[:, 1]]
    v2 = vertices[T[:, 2]]
    edge_a = torch.cat([v0, v1, v2], dim=0)   # [3P, 3]
    edge_b = torch.cat([v1, v2, v0], dim=0)   # [3P, 3]

    # 置信权重（stop-grad，不参与反传）
    opacity = torch.sigmoid(vertex_weight.squeeze(-1)[T]).min(dim=1).values  # [P]
    imp = importance_score.squeeze()[:P]                                       # [P]
    omega = (imp * opacity).detach()
    tri_owner = torch.arange(P, device=dev).repeat(3)     # [3P]
    omega_per_edge = omega[tri_owner]                      # [3P]

    # 邻居边端点
    cands = edge_candidates.to(dev)   # [3P, k]
    ne_a = edge_a[cands]              # [3P, k, 3]
    ne_b = edge_b[cands]              # [3P, k, 3]

    ea = edge_a.unsqueeze(1)  # [3P, 1, 3]
    eb = edge_b.unsqueeze(1)  # [3P, 1, 3]

    # 双向边距离（考虑方向翻转）
    d1 = (ea - ne_a).pow(2).sum(-1) + (eb - ne_b).pow(2).sum(-1)   # [3P, k]
    d2 = (ea - ne_b).pow(2).sum(-1) + (eb - ne_a).pow(2).sum(-1)   # [3P, k]
    D = torch.minimum(d1, d2)                                        # [3P, k]

    # Softmax 匹配权重（stop-grad，只决定哪条邻边更重要，不参与反传）
    P_ef = torch.softmax(-D.detach() / tau, dim=-1)  # [3P, k]

    return (omega_per_edge * (P_ef * D).sum(-1)).mean()


def opacity_solidification_loss(
    vertex_weight: torch.Tensor,
    triangle_indices: torch.Tensor,
    importance_score: torch.Tensor,
    importance_threshold: float,
) -> torch.Tensor:
    """
    实体化 loss：

        L_opaque = mean_i [ m_i * (1 - o_i)^2 ]

    m_i = 1 若 importance_score[i] > importance_threshold，否则 0。
    只对高置信三角形施加"变不透明"的压力。

    Args:
        vertex_weight:        [V] logit 空间
        triangle_indices:     [P, 3]
        importance_score:     [P] or [P,1]
        importance_threshold: 与 train.py 中 prune_triangles 对齐即可
    """
    T = triangle_indices.long()
    P = T.shape[0]
    o_per_tri = torch.sigmoid(vertex_weight.squeeze(-1)[T]).min(dim=1).values  # [P]
    mask = (importance_score.squeeze()[:P] > importance_threshold).float().detach()
    return (mask * (1.0 - o_per_tri).pow(2)).mean()
```

    def compute_area_loss(self, a_min: float = 1e-6) -> torch.Tensor:
        """面积下限保护：防止实体化阶段三角形退化为线或点。"""

## 七、已知限制与后续扩展

| 限制 | 说明 | 后续方案 |
|------|------|---------|
| sigma 为全局标量 | L_σ（per-triangle sigma loss）无法实现 | 需改 forward.cu 接口，工程量较大，建议单独立项 |
| 多视角可见性计数 | 当前用 importance_score 代替 V_i，不是严格的多视角统计 | 在 train.py 中加 view_count tensor，每次 render 后累加 was_rendered > 0 的三角形 |
| KDTree 建图速度 | 三角形很多（>100万）时较慢，约数十秒 | 换 FAISS GPU 加速；或降低重建频率（每 1000 iter 而非每 500 iter） |
| Hard welding | 训练结束后将软连通分数转为实际顶点合并 | 独立后处理脚本，参考 PDF §11，不影响训练代码 |

## 九、实现后修复记录

### 9.1 Bug：connectivity_loss tensor size mismatch

**现象**：训练在 prune 后首次触发 L_conn 时崩溃：
```
RuntimeError: The size of tensor a (33682485) must match the size of tensor b (4867836)
```

**根因**：`edge_candidates` 在 `prune_triangles` 之后、`add_new_gs` 之前构建，`add_new_gs` 改变了 `P`，导致下一次迭代进入 `connectivity_loss` 时 `edge_candidates.shape[0] != 3*P`。

**修复 1**：`train.py` 中将 `build_edge_candidates` 调用移至 `add_new_gs` **之后**（原文档 4.3 节的插入位置描述有误，已更正为下方）：

```python
                if needs_densification:
                    triangles.add_new_gs(...)

                # ← 必须在 add_new_gs 之后重建
                if lambda_conn_max > 0:
                    edge_candidates = build_edge_candidates(
                        triangles.vertices,
                        triangles._triangle_indices,
                        k=k_edge,
                    )
```

**修复 2**：`connectivity_loss` 函数顶部加 shape guard，在 P 与候选图不匹配时安全返回 0：

```python
    if edge_candidates.shape[0] != 3 * P:
        return torch.tensor(0.0, device=dev)
```

---

### 9.2 Bug：Delaunay 后 edge_candidates 索引过期

**现象**：Delaunay 重网格化（iter 11001）会完全重建 `_triangle_indices`，而 `edge_candidates` 最后一次重建在 iter 10500（densification 窗口内最后一个 500 倍数）。从 Delaunay 到 solidification 启动（iter 20000）之间约 9000 步，`edge_candidates` 基于旧拓扑，shape guard 只能挡住 P 改变的情况，P 恰好相同时会用错误索引静默计算。

**修复**：在 `triangles.run_restricted_delaunay()` 调用后立即重建候选图：

```python
        if need_delaunay:
            with torch.no_grad():
                triangles.run_restricted_delaunay()
            need_delaunay = False
            if lambda_conn_max > 0:
                edge_candidates = build_edge_candidates(
                    triangles.vertices, triangles._triangle_indices, k=k_edge)
```

post-Delaunay 的 `elif` 分支只更新 opacity floor，不做 prune，拓扑稳定，重建一次即可。

---

### 9.3 改动：`render.py` 显存溢出

**现象**：训练完成后执行 render.py 报 CUDA OOM。

**原因**：原代码硬编码 `triangles.scaling = 4`（supersampling ×4），tile buffer 在全分辨率下爆显存；且多帧循环无缓存释放。

**修复**：
1. `render_set` 循环末尾加 `torch.cuda.empty_cache()`
2. `scaling` 改为命令行参数 `--scaling`，默认值 `1`（原始分辨率），需要高质量输出时手动传 `--scaling 4`

```python
# render_sets 签名
def render_sets(..., scaling: int = 1):
    triangles.scaling = scaling

# 新增 argparse 参数
parser.add_argument("--scaling", default=1, type=int)
```

## 十、快速测试参数（当前 `arguments/__init__.py` 默认值）

为快速跑通完整训练流程，将所有 iteration 阈值按 **1/5** 缩放至 6000 iter。  
正式实验时通过命令行覆盖，例如 `--iterations 30000 --densify_until_iter 10000 ...`。

| 参数 | 原始值（30k） | 当前默认（6k） |
|------|-------------|--------------|
| `iterations` | 30000 | 6000 |
| `position_lr_max_steps` | 30000 | 6000 |
| `densify_from_iter` | 500 | 100 |
| `densify_until_iter` | 10000 | 2000 |
| `start_pruning` | 4000 | 800 |
| `start_opacity_floor` | 5000 | 1000 |
| `start_vertex_opt` | 12000 | 2500 |
| `start_upsampling` | 20000 | 4000 |
| `final_opacity_iter` | 24000 | 5000 |
| `solidification_start` | 20000 | 4000 |
| `sigma_until` | 30000 | 6000 |
| `iteration_mesh` | 5000 | 1000 |

**注意**：`start_upsampling + 5000`（train.py 硬编码）= 9000 > 6000，故 ×4 supersampling 在 6k 训练中不会触发，模型以 ×2 结束。
